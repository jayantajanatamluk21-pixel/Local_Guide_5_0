# LocalGuide 4.0 release notes

Version 4.0 is additive over 3.2.1. It retains invite-token admin isolation, guest/member map privacy and validated authentication intent. The new design/motion layer, member collections, notifications, community feed, profile preferences, versioned API, backup launcher and admin system-health panel are included. See `FEATURE_MATRIX.md` for exact boundaries.

Before go-live: replace demo content, update `.env` for HTTPS/canonical host, rotate administrator credentials and invitation token, verify location coordinates and legal map tile use, schedule the backup utility, and configure any required AI/payment/messaging/map providers.
